One file, every country

Everything on this site comes from one JSON file, rebuilt every day after the European day-ahead auction (about 13:00 Central European time). Download it once per session and read the price for the current time. There is no API key and no rate limit, and it can be fetched from any web page.

Reading a price

Prices are per kWh, all taxes and fees included, in the currency households are billed in. fx gives units per euro. Each country has an average, and some have zones (regions, states, bidding zones) with the same fields. Live countries carry a series: one price per 15 or 60 minutes from start. Every entry has a flat price for when there is no series, except North Korea's.

const url = "https://mattiawasfound.github.io/energy-prices/v1/prices.json";
const file = await (await fetch(url)).json();

function priceNow(entry, now = Date.now()) {
  const s = entry.series;
  if (s) {
    const i = Math.floor((now - Date.parse(s.start)) / (s.step_minutes * 60000));
    if (i >= 0 && i < s.values.length) return s.values[i];
  }
  return entry.flat ?? null;   // null: no published price
}

const dk = file.countries.DK;
priceNow(dk.average);                          // DKK per kWh
priceNow(dk.average) / file.fx[dk.currency];   // EUR per kWh

How sure each price is

basis says where a figure came from and precision how far to trust it. A client should show both, and an entry's reason when it has one.

Caveats

  • These are rough household figures, not tariffs. A real bill depends on the supplier, the contract, the consumption and local fees.
  • Prices are converted at official exchange rates, which flatter countries whose street rate is far weaker (Cuba, Iran, Lebanon, Venezuela and a few more).
  • Tables are updated by hand; each row says the month it describes.
